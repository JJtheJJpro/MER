# JJ's Mega Executable Reader

MER stands for Mega Executable Reader.  Written in TypeScript as scripting and in Rust as compiling, this will have the capabilites to parse any executable.

As for right now, I'm still in the process of working out 16-bit executables for Windows 3.x.
Once each of those have been successfully parsed and decompiled, I will then move on to modern windows executables, which then, after successful, have this go into its Alpha stages.
